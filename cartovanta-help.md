# cartovanta

The command-line toolchain for working with _CartoVanta_ card decks.

## Usage
- `cartovanta [subcommand] [arguments]` : Executes the `subcommand` subcommand
- `cartovanta [subcommand] --help` : Displays helpfile for the `subcommand` subcommand
- `cartovanta [subcommand] --share-resdir` : Outputs the location of the resource directory for the `subcommand` subcommand. (NOTE: This option has not yet been implemented.)
- `cartovanta --help` : Displays this helpfile
