# cartovanta
Basic tools of the -cartovanta- card system

## TWO SUB-REPOS
Within this repo, you will find two directories,
`archaic` and `newform`. This is because this project
is in the midst of a major redesign at its core.

Currently, `archaic` is the working form of the project.
If you want to install it, go there. (The `README.md`
file there will tell you all you need to know.)

The `newform` is the future version which is not yet
ready, and not yet even functional -- but is already
under construction.
